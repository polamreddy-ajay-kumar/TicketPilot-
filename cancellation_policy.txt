Order Cancellation Policy

A customer may request cancellation while an order is still being processed and has not entered fulfillment. Once an order has entered fulfillment or has been dispatched, it cannot be cancelled; the customer may instead follow the Refund and Returns Policy after delivery if the item is eligible. Cancellation requests must include the order number. An order that has not yet left the warehouse can be cancelled only if it has not entered fulfillment; not being dispatched yet does not by itself make an order cancellable. If the order has already entered fulfillment it cannot be cancelled, even though it has not been dispatched. Customers who are unsure should contact support with the order number so the current order status can be checked. This policy covers physical orders only and does not define rules for subscriptions or recurring services.
